## Rules

- Use mint (`#42bd91`) for active tabs, selected exchange accounts, and primary actions
- Use `emerald-500` for positive PnL, confirmed states, and success messages
- Use `red-400` for losses and errors
- Use amber (`#f3aa32`) for attention and pending states
